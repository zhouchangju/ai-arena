# macOS 试用指引

[从源码构建并打开 AI Arena](../README.md#从源码运行)。首次使用时，在应用内打开各席原页并按站点提示登录。Chrome 里的登录会话与应用的 WebKit 登录会话分别保存。

## 调整外观

从「AI Arena → 设置」打开外观设置，也可按 ⌘, 或点击主窗口右上角的齿轮。工作台默认跟随 macOS 外观，可以切换为浅色或深色。三家站点的原页各自决定网页主题。

顶部提问区可以使用内置渐变、纯色或本地 PNG、JPEG。选图后应用会在本机保存一份用于显示的副本，下次打开仍会使用。外观设置里可以更换图片或恢复默认背景。

## 跑一场讨论

1. 输入问题，点「开始讨论」或按 ⌘↩。默认由 ChatGPT、Gemini、DeepSeek 三席参与。例如「如果我只有两个周末，个人笔记工具应该先做手机采集，还是先改进桌面搜索？」
2. 想换席或调整轮次，点输入框下的席位摘要，再点一次收起。至少保留两席。互评默认最多 3 轮，可选 1–5 轮。每一轮从互评开始，之后起草或修订候选并请各席表态，独立作答阶段不显示轮号。开始互评后，阶段、报告和导出显示「互评第 N 轮 / 上限 M」。
3. 各席先独立作答，再看其他席的原文并提出质疑。查看各席状态和原网页，必要时用「查看当前提示」核对本轮发送内容。状态用固定类别显示，具体原因在第二行或悬停说明里；需要行动的席位会标为「需要你处理」。
4. 起草席给出带出处的候选，各席对同一版本表态。仍有反对或附加条件时，工作台可以在剩余轮次内安排定向互评和新一版确认；达到上限后，报告保留未决意见。

**可以同时使用其他浏览器。** Arena 核对首轮提问后，会记住每一席在本站的对话地址。你可以在 Chrome、Safari 等浏览器另开 Gemini、ChatGPT 或 DeepSeek 聊天。各席后续互评、起草和表态继续使用本场对话，无需关闭外面的标签页。如果原站要求重新登录或已无法打开本场对话，按该席提示处理。

## 带图或文件提问

开场需要填写讨论问题。例如，输入「对比图 1 和图 2，哪一版更容易找到导出按钮？」接着把截图复制到剪贴板，在问题框按 ⌘V，重复粘贴即可追加。也可在 Finder 多选文件后复制粘贴、拖入提问区，或点「添加附件」选择文件。开始前逐项核对预览和顺序，移除多余材料，再确认所选席位。

- **PNG、JPEG 和剪贴板截图**随首轮问题发给所选席位。后续互评沿用各席原对话。
- **TXT、MD 和 CSV**按 UTF-8 读取。可以先预览，确认后文件正文会写入各席的首轮提示。PDF、Word 和 Excel 原文件暂未开放。

每场最多 8 个附件，共 24 MiB。每张图片最多 8 MiB、4000 万像素，所有文本文件合计最多 24 KiB。

若有一席停在「需要你处理」，先看这一席原页。题面还在输入框时，先查看已挂的图片。需要补图时，点题面旁的回形针进入「开场附件」，点图片旁的文件夹图标在 Finder 中定位本场原件，再把缺少的图片拖入该席原页。粘贴的截图也能在这里找到。若题面已经发出，先核对已发消息中的附件和随后的回答，避免重复发送。手动补录时，核对原页后勾选「已在本席原页核对本轮问题和全部附件」。如果原页无法核实材料是否齐全，可跳过该席。[逐站验证记录](provider-validation.md)

## 中断、接管与恢复

- **席位切到了另一段对话**。工作台会尝试回到本场保存的对话。已经发出或可能发出的提问只读回，不会重发。如果当前页有草稿，先保存草稿。如果还在生成，先等它结束。然后点席位上的「回到本场对话并恢复」。如果站点打不开原对话，可用「查看当前提示」核对轮次，找到这条提示对应的完整回答后用「文本补录…」提交。找不到时可选「跳过本席…」。
- 写好题面和附件后可以先回看历史。点「返回草稿」会带回原题和原顺序的附件。
- 「暂停」停止后续自动派发，阶段标记同时变为暂停色。原站已经收到的请求仍可能继续生成。
- 某席卡住时，在该席菜单选择「人工接管」。接管只切换状态，补录面板不遮挡原页；面板预填已保存回答，尚未保存时使用最新流式预览并标注「部分预览」。先检查原页是否已有本轮提问和回答，再补录或选择「跳过本席」。跳过需要确认，并计为缺席。确认站点就绪后，可用「恢复本站自动」。
- 重开应用会恢复上次讨论。顶部「历史」按钮或菜单栏「显示 → 历史…」（⌘⇧F）一键打开历史面板：默认聚焦搜索，列出最近场次，可筛选状态、结果和席位。用 ↑↓ 移动当前选择，Return 只读回看，Esc 关闭；也可以直接用鼠标点选条目或按钮。面板复用应用启动时装入的本机场次摘要，打开时不重扫磁盘；在其他程序改动场次目录后，点面板顶部的刷新按钮重新读取。已完成场次只能回看；未完成的场次可在新建、关闭窗口或退出后从历史或只读视图选择「继续这一场」，沿用只读核对、绝不重发的续跑路径。
- 讨论运行中，点「更多」可新建或结束整场。这两个操作和关闭主窗口都会先确认。「结束」结束整场，已完成场次之后只能回看、不能继续；关闭窗口或退出确认后不再发起新的发送，但已发送的请求仍可能在原站生成。

## 阅读并导出报告

报告保存后点「查看报告」。回看已完成的历史场次时，报告直接显示在主窗口。先读建议和各席表态，再展开发言、互评和出处。点击 `[S#]` 可查看对应原文。点击「复制报告」后，窗口内会短暂显示「已复制到剪贴板」。题面、提示、历史原文与 JSON 的复制沿用相同的反馈。用「导出」保存 Markdown，文件写入后会显示导出结果。导出状态按保存的场次生成，时间使用本机时区。

Arena 在后台运行时，整场讨论结束且报告已保存后，会发出一条 macOS 通知。使用系统通知需要允许 AI Arena 发送通知，权限可在「系统设置 → 通知 → AI Arena」中调整。切回 Arena 后，也可以从「详情」或「历史」查看报告。

带附件的场次在完整报告的「开场附件」里列出文件、发送方式和逐席核对状态。要重看图片或文本，打开历史场次并点击附件。Markdown 导出保留这份清单，原件保存在本机场次目录。

如果想比较模型，讨论结束后点报告里的「评估本场」。工作台用应用内已登录的 ChatGPT 打开新会话，把题面、附件和去掉席位标签的独立作答交给裁判。一次请求比较所有对阵，结果包括胜负、理由和可回看的来源。需要核对一组时，可点「交换顺序复判」。复判冲突或证据不足时保留对阵结果，无法得到一致排序时不强制列名次。评估保存在本机场次下，历史报告可继续查看。ChatGPT 也参赛时，结果会标明这一点。

试用时可核对四件事：独立作答是否收到同一题面，互评提示是否包含正确的他席原文，报告是否按同一候选版本呈现表态，导出是否保留出处与分歧。已完成的真实站点检查见[站点验证](provider-validation.md)。

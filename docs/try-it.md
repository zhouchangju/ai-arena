# macOS 试用指引

[从源码构建并打开 AI Arena](../README.md#从源码运行)。首次使用时，在应用内打开各席原页并按站点提示登录。Chrome 里的登录会话与应用的 WebKit 登录会话分别保存。

## 跑一场讨论

1. 选 ChatGPT、Gemini、DeepSeek 中的两席或三席，输入问题。例如「如果我只有两个周末，个人笔记工具应该先做手机采集，还是先改进桌面搜索？」
2. 选择互评上限，默认 3 轮，可选 1–5 轮。点击「开始讨论」或按 ⌘↩。
3. 各席先独立作答，再看其他席的原文并提出质疑。查看各席状态和原网页，必要时用「查看当前提示」核对本轮发送内容。
4. 起草席给出带出处的候选，各席对同一版本表态。仍有反对或附加条件时，工作台可以在剩余轮次内安排定向互评和新一版确认；达到上限后，报告保留未决意见。

## 中断、接管与恢复

- 「暂停」停止后续自动派发。原站已经收到的请求仍可能继续生成。
- 某席卡住时，在该席菜单选择「人工接管」。先检查原页是否已有本轮提问和回答，再选择「文本补录」或「跳过本席」。确认站点就绪后，可用「恢复本站自动」。
- 重开应用会恢复上次讨论。「历史」可打开其他场次。未完成的派发先核对原页，避免重复发送。

## 阅读并导出报告

从「详情」打开报告窗口。先读建议和各席最终态度，再展开发言、质询和出处。点击 `[S#]` 可查看对应原文。用「导出」保存 Markdown。

试用时可核对四件事：独立作答是否收到同一题面，质询提示是否包含正确的他席原文，报告是否按同一候选版本呈现态度，导出是否保留出处与分歧。已完成的真实站点检查见[站点验证](provider-validation.md)。

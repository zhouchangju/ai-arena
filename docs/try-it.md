# 试用指引

直接加载即可用：九个原生站点手动中转，本机 A / B 配好后可自动派发。自动接力已用确定性夹具实跑一轮七次提交；真实站点的自动收发未验。对应 G1–G4。

## 1. 加载扩展（约 1 分钟）

1. 打开 `chrome://extensions`，右上角开「开发者模式」。
2. 点「加载已解压的扩展程序」，选仓库里的 `extension/`（含 `manifest.json` 那一层，不是仓库根目录）。
3. 点工具栏图标打开工作台；再点一次会切回同一个标签，不会另开一个。
4. 改过扩展文件后，回 `chrome://extensions` 点这张卡片上的刷新图标，再重新打开工作台。只刷新页面不算重载扩展。

## 2. 手动跑一场

1. 首页「问题」里写下要判断的事，在「选择两个或三个 AI」点不同的卡（两席即可开始），点「开始讨论」，或按 ⌘ / Ctrl + Enter。
2. 第一次自己选席。之后再重新打开工作台，如果问题和选择都还空着，会沿用上一次实际开始的席位，并提示「沿用上次的 ChatGPT 和 Claude」这类文字；动过选择或写了问题就不再套用。
3. 每阶段每席两个主动作：
   - 点「复制提示并打开原页」：一次复制本轮提示并切到这一席的原页（已绑定的原页会复用当前标签）。
   - 在原站粘贴、发送、等写完 → 全选复制 → 回来点「粘贴回答」，粘进「回答原文」→「提交回答」。
   页面上方还有一条「下一步」，指向仍要手动处理的那一席，按钮和上面一样；不想自己找卡就点它。
4. 只想复制、不想跳转，或要直接记缺席：展开这一席的「更多操作」，里面有单独的「复制提示」「打开原站」和「跳过这一席」。跳过会先确认，这一阶段记为缺席，不算同意。
5. 跳过的席位若之前存过没提交的草稿，卡片里会单独显示「未提交的草稿」：可展开看原文、点「复制草稿原文」，但它只是本机留存，不算回答，也不进逐席确认或报告。
6. 提交过的席位变成「已收到」，正面只留已保存的原文和「复制回答」，不能再补交。独立作答、交叉质询这两段里，只要同一轮还有待答席位（本轮尚未冻结），这一席的「更多操作」会多出「改正录入」：打开时已预填这一席的最新原文，改完点「保存更正」，本席仍只算一条回答；下一阶段提示改用更正后的文本，首次提交的原文留在「更正前后」里可展开、复制。同轮待办全部处理后本轮冻结，这时以及逐席确认的表态、「历次发言」都只读，只能看和复制。
7. 顺序：独立作答 → 交叉质询 → 候选结论 → 逐席确认 → 结论。
8. 示例问题：`我只有两个周末，个人笔记工具先做手机版，还是先把搜索做好？`
9. 质询提示里应出现其他已答席位的原话和 `[S1 · chatgpt · independent · 第1轮]` 这类来源块；没有就说明取回的文本不对。
10. 候选结论提示的材料逐条带编号。提交时引用了不存在的 `[S#]` 会被拒绝，错误里列出本场有效编号，也不会发起表态；改掉后在「候选结论原文」重新提交。一条编号都不写也能提交，但报告只按草稿算。
11. 逐席确认：选「明确立场」（同意 / 有条件同意 / 反对）→ 在「理由（必填，会存为回答原文）」写理由 →「记录表态」。缺席与沉默都不计为同意。
12. 中途想加约束：先点「暂停」，页面出现「补充判断条件」→ 写下条件（例如“预算上限两万元”）→「保存条件」。条件只写入本场记录，供**之后新建的任务**使用，不改动当前提示也不自动发送；它只在独立作答与交叉质询两段可填，恢复讨论后可继续提交。

## 3. 读结论与导出

「结论」页先看建议本身：状态标签（全体一致 / 有条件一致 / 仍有明确反对 / 部分完成 / 草稿等）和一句说明在最上面，接着就是「建议回答」；还没形成一致时标「候选建议」，没有候选就显示当前状态。有未解决的反对或附加条件时，紧接着列「尚未解决的条件与反对」。未删改的完整 Markdown 报告和状态记录收在可展开的「完整报告与状态记录」里。报告里的 `[S#]` 可点，会跳到「历次发言」的对应原文并高亮；缺少可核实出处时状态会按「草稿」处理。「导出 Markdown」保存 `AI-Arena-问题-YYYYMMDD.md`；「复制结论」只复制报告文本。左侧「我的讨论」能重开、能按问题搜索，刷新或关掉再开都不会重发提示；「删除记录」只删本机。

## 4. 小屏看历史

窗口窄于 980px 时，侧边栏收成顶部右侧的「历史」：点开是「查找讨论」和讨论列表，选中一场后自动收起；Esc 或点空白处也能收起。首页上的「连接设置」入口照旧可用。

## 5. 本机两席自动（可选）

在**仓库根目录**另开一个终端，启动夹具服务并保持运行（端口用 `8877`；本机已有的其他服务端口不要动，若 `8877` 被占用，换一个空闲端口并让两席地址与启动命令保持一致）：

```bash
python3 -m http.server 8877 --bind 127.0.0.1 --directory tests
```

浏览器打开 `http://127.0.0.1:8877/web-driver-fixture.html?seat=A` 能看到「Web Driver 夹具」页，说明服务已就绪。

然后按这个顺序配好两席并启动：

1. 首页点「连接设置」打开「网页连接」→ 点「填入本机测试页配置」（两席地址分别是 `?seat=A` 与 `?seat=B`，端口 `8877`）→ 两席分别点「保存本席」。Chrome 会弹原生权限框，得你在自己的浏览器里点允许；无头测试用的是临时副本（回环地址已预授权），生产目录没改。
2. 回到工作台，新建一场（不要复用旧场次）：写问题 →在席位选择区点「本机 A」和「本机 B」→「开始讨论」。
3. 场次页点「开始自动化」，只驱动已配置的两席；可「停止自动化」或「刷新自动状态」。自动席位在跑时不再摆手动按钮，要自己接手就展开这一席的「更多操作」。

夹具回答由本地哈希生成、带 `[FIXTURE seat=…]`，是确定性样本不是模型输出，别写进真实报告。

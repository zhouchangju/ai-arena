多 AI 讨论怎么推进？

模型作答、互相质疑、起草和表态。工作台负责转交材料、管理轮次，并按各席的有效表态与参与记录生成报告。

讨论步骤

  1. 提交问题并选席 从 ChatGPT、Gemini、DeepSeek 选 2–3 席。
  2. 各席独立作答 分别收到同一题面，此时彼此的答案不可见。
  3. 交叉互评 首轮评各席原文，后续轮回应未决争点。
  4. 一席起草或修订候选 保留条件、争点与出处；修订后生成新版本。
  5. 各席对同一候选表态 明确同意、有条件同意或反对，并给理由。
  6. 继续还是结束？
    • 还有互评轮次：有反对，或票齐且有条件，带着候选和争点继续互评，回到「交叉互评」。
    • 满足全部一致条件：全体一致报告，保留最终版本、逐席表态和出处。
    • 其余结束情形：按当前结果出报告，包括有条件一致、未决分歧、部分完成或草稿。

三席怎么互评？

独立作答阶段结束后，工作台用同一批已保存的回答，为每个已作答席位生成一份互评提示。

B 的回答 ＋ C 的回答
B
A 的回答 ＋ C 的回答
C
A 的回答 ＋ B 的回答

每份提示也附原题和本席原文。各席各交一份互评，指出最强反例，并说明自己维持或修正了什么。

续评改看候选和未决争点　各席收到当前候选及反对意见或附加条件原文，逐条回应。

什么情况下算全体一致？

  1. 开场选定的每一席都有独立回答，并完成了最后一轮互评。
  2. 每一席都对同一版本的完整正文明确、无条件同意。修订后重新表态，旧票留在历史。
  3. 候选至少有一条能定位到本场发言的出处，例如 [S3]。出处用于回看原文。

新建桌面场默认最多 3 轮互评，可设 1–5 轮。独立作答在互评前完成。存在明确反对时，可以在预算内继续互评，即使票未收齐。只有附加条件时，票齐才会续评。

单席卡住时怎么办？

工作台先保存实际提示和发送意图，再到原站投递；确认回答完成后才交给讨论引擎。发送状态不明或从历史续跑时，先核对绑定的原对话。也可以手动补录或跳过该席。缺席、沉默和无效票均不计为同意。

用户可以提前结束。若没有可用答复、没有互评材料，或可接替的席位也未交出候选，讨论会提前收尾并保留已收到的材料和停止原因。报告可按出处回看并导出 Markdown。

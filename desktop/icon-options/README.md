# AI Arena 图标候选

## 圆桌方向 · 第二轮候选

已选定的设计方向是“三席围桌”。桌面留白，用座位朝向、人物姿态或负空间表现讨论。第二轮使用 A–E 编号。请同时观察大图和每款下方的 32、16 像素效果。 [五款对比图](roundtable/choices.png)

| 编号 | 原图 | ImageGen 设计提示 |
|---|---|---|
| A | [青瓷会客厅](roundtable/A-porcelain.png) | 斜俯视白瓷圆桌，三把钴蓝曲木椅朝向桌心，浅蓝陶瓷底板。 |
| B | [朱印议席](roundtable/B-seal.png) | 正俯视朱红实心桌面，三枚墨黑人形按 120° 排列，米白底色。 |
| C | [琥珀夜谈](roundtable/C-lantern.png) | 琥珀玻璃圆桌边沿透光，三把低矮青绿围椅置于深色背景。 |
| D | [折纸三人组](roundtable/D-fold.png) | 三位黄、蓝、珊瑚红折纸人物面朝素色圆桌，保留纸张折面和投影。 |
| E | [青玉同席](roundtable/E-inlay.png) | 以浅青玉浮雕刻出桌面和三道弧形椅背，深松绿底板强调间隙。 |

五张独立透明 PNG 由内置 ImageGen 生成。共用约束为三席平等、桌面完整空白、小尺寸轮廓清楚。选定后再更新应用资源 `desktop/assets/ArenaIcon.icns`。

验收步骤
  1. 装扩展后在该标签页注入 extension/web-driver.js；工作台用 frameId: 0 发消息。
  2. arena.web.probe 应返回 ready，并显示当前草稿是否为空。
  3. arena.web.submit 使用上面选择器与一个 taskId；返回 submitted 后轮询 arena.web.read。
  4. 用 slow 观察 pending；用 nostop / nodone 验证两种完成证据；用 nosignal 验证永不误判。
  5. 用 duplicate / stale / reorder / empty 验证旧文本、错序与空回答都被拒绝。
  6. 先注入旧草稿再提交不同 prompt，应返回 draft-conflict 且草稿不被覆盖。
  7. 刷新页面后对旧 taskId 调 arena.web.read，应返回 unknown。

夹具仅存在于 tests/。无外部请求、无账号、无真实模型；回答内容由 seat + round + prompt 的本地哈希决定。 STANCE: 是本页唯一可解析的立场行（只取 agree / conditional / oppose 之一），其余文字只是测试素材。
